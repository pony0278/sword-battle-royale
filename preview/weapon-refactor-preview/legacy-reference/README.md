# Legacy reference map

Phase A keeps the executable Punch Studio sources for behavior comparison but does not load them from Action Studio.

- `tools/punch-studio.legacy.html` — preserved legacy browser entry.
- `tools/ps/pose-data.js` — legacy pose/timeline/editor state source.
- `tools/ps/rig.js` — legacy procedural rig, pose application and grounding source.
- `tools/ps/editor-ui.js` — legacy editor interaction source.
- `tools/ps/hitfeel.js` — legacy presentation preview source.
- `tools/ps/game-bridge.js` — legacy clip library/combo/game-camera source.
- `tools/ps/parts.js`, `sockets-data.js`, `avatar.js`, `slim.js` — future UGC/equipment reference only.

`actor-brawler.js` was named in the extraction brief but is not present in this repository, so no local copy or invented replacement is included.
